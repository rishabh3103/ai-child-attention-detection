# AI-Based Child Attention Detection System

## Overview
A real-time AI-powered attention and emotion detection system using Machine Learning and Computer Vision techniques.

## Features
- Attention detection using SVM
- Emotion recognition using CNN
- Real-time webcam monitoring
- GUI visualization
- EAR and head pose analysis

## Technologies Used
- Python
- OpenCV
- TensorFlow
- dlib
- CustomTkinter
- Machine Learning

## Project Structure
- src/ → Source code
- models/ → Trained ML models
- results/ → Output images/results

## Note
Large datasets and pretrained landmark files are not uploaded due to GitHub storage limitations.
